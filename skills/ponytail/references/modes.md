# Ponytail modes

All modes preserve the full requested behavior and required safeguards.

| Mode | Emphasis |
| --- | --- |
| lite | Implement the request and mention a materially simpler alternative if useful. |
| full | Prefer existing code, standard libraries, and native facilities; avoid speculative flexibility. Default when Ponytail is explicitly invoked without a mode. |
| ultra | Challenge unrequested layers and speculative additions more aggressively. Remove them only when behavior and compatibility remain intact. |

Use the current runtime's skill invocation syntax. A mode is a preference within the user's requested scope, not permission to omit features or persist into unrelated tasks. Follow a later request to change or end the mode.
