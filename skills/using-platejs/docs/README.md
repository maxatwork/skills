# Plate documentation mirror

Source: [https://platejs.org/docs](https://platejs.org/docs)

This mirror contains the 126 live routes that currently provide the site's `.md` response. The live HTML route graph contains 265 routes; 139 generated routes do not expose Markdown and are listed in [`_markdown-unavailable-routes.md`](_markdown-unavailable-routes.md).

The route-to-file mapping and crawl results are in [`_manifest.json`](_manifest.json). The `/docs` landing page is [`index.md`](index.md).
